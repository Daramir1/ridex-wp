# rideX

Одностраничный адаптивный сайт эндуро-проката в Киеве.

## Что внутри

- парк мотоциклов и тарифы;
- блок подарочных сертификатов;
- схема локации и контакты;
- форма записи с email и подтверждением;
- мобильное меню и адаптивная верстка;
- Open Graph-превью для публикации ссылок.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации: `npm run build`.

Фотографии: Unsplash — Leo_Visions, The Ordinary Moments, Tristan Frank и Luke Uhrle.
