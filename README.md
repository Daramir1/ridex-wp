# RideX WordPress Theme

Кастомная WordPress-тема для сайта проката эндуро-мотоциклов.

## Возможности

- адаптивная одностраничная вёрстка;
- динамический список мотоциклов;
- динамические тарифы;
- поля главной страницы через ACF;
- форма записи через Contact Form 7;
- сохранение локальных заявок через Flamingo;
- конфигурация ACF хранится в `acf-json`.

## Необходимые плагины

- Advanced Custom Fields
- Contact Form 7
- Flamingo

## Установка

1. Скопировать папку `ridex-wp` в `wp-content/themes`.
2. Активировать тему в WordPress.
3. Установить необходимые плагины.
4. Открыть ACF и синхронизировать доступные JSON-конфигурации.

## Разработка

Проект разработан локально с использованием XAMPP.
